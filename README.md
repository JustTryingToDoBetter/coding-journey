# coding-journey

A single-page roadmap dashboard for tracking a 24-week technical growth plan.

## What is in this repo

- `index.html`: Complete app UI, styles, and logic (no build step required).

## Run locally

Because this is a static page, you can open it directly in a browser.

Option 1:
- Double-click `index.html`.

Option 2 (recommended, local static server):
- `python3 -m http.server 8080`
- Open `http://localhost:8080`

## Notes

- Progress is saved in `localStorage` in your browser.
- No package manager or additional dependencies are required.
